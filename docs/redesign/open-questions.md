## Pre-delivery hardening pass — all closed

Found by auditing the built output and a running production server, not by reading code.
Each was verified fixed against a real build (295 automated delivery checks, plus a
structural accessibility sweep over all 24 page × locale combinations).

| #   | Issue                                                                                                                                                                                                                                                                                                                                | Resolution                                                                                                                                                                                                                                                                                                                                       |
| --- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| D1  | **`/en/*` was an infinite redirect loop.** The `$locale` layout redirects `/en/*` to `stripLocale(pathname)`, but `stripLocale` left `/en` in place — so `/en` redirected to `/en`. Masked in production by the `vercel.json` edge rule, which rewrites before a function runs; the app must not depend on one config file for that. | `stripLocale` now strips the default locale too. `/en`, `/en/about`, `/en/teach` resolve in **one hop**; `/he` + `/ar` unchanged; `/fr` still 404s; `/enroll` (merely starts with "en") untouched.                                                                                                                                               |
| D2  | **`/he/*` and `/ar/*` had no real 404.** A bad path under a locale prefix resolves against `$locale`, which defined no `notFoundComponent`, so it never reached the root's and fell through to TanStack's bare built-in "Not Found" — unstyled English on an RTL page. Only the EN 404 worked.                                       | Screen extracted to `src/components/site/NotFound.tsx` and registered as **both** the root's `notFoundComponent` and the router's `defaultNotFoundComponent`, which covers subtrees without their own.                                                                                                                                           |
| D3  | **404 + error screens were hard-coded English**, so `/he/*` and `/ar/*` rendered English inside `dir="rtl"`, and "Return home" dropped the locale. Contradicts `i18n.md` ("error messages localize").                                                                                                                                | Localized via `common.json` (`notFound.*`, `errorPage.*`) in all three catalogs, linking to the locale's home. They use `metaT()` rather than `useTranslation()` because they can render in place of the component that mounts the provider. The last-resort SSR fallback page is localized too, from an inlined table so it cannot itself fail. |
| D4  | **The hard-coded-string gate had a blind spot** — it scanned only `src/pages` and `src/components/site`, which is exactly how D3 shipped unnoticed.                                                                                                                                                                                  | Now walks `src/routes` recursively: **35 files, up from 17.** Proven by negative control (reintroducing a literal fails the build).                                                                                                                                                                                                              |
| D5  | **`twitter:title` / `twitter:description` were generic English on all 24 pages.** The root set them and `pageHead()` never overrode them; X prefers `twitter:*` over `og:*`, so the Arabic homepage previewed with English text.                                                                                                     | `pageHead()` emits both per page × locale. Verified in built HTML: exactly one of each, matching the localized `og:title`.                                                                                                                                                                                                                       |
| D6  | **Skipped heading levels** (h2 → h4) on About and Schools — IS 5568 / WCAG 1.3.1, and called out in `accessibility.md`.                                                                                                                                                                                                              | Card and step titles corrected to `h3`. Sizing comes from utility classes, so **visually identical**. All 24 pages now: one `h1`, no skips.                                                                                                                                                                                                      |
| D7  | **No `Sitemap:` directive** — the sitemap existed but nothing advertised it.                                                                                                                                                                                                                                                         | `robots.txt` now served from a handler so its sitemap URL comes from the same `SITE_URL` as canonicals/hreflang — no static file left pointing at the old domain after cutover.                                                                                                                                                                  |
| D8  | **`npx tsc --noEmit` failed**, and nothing ran it. `vite.config.ts` passed `customViteReactPlugin`, removed from the installed `@tanstack/react-start` — silently ignored.                                                                                                                                                           | Option dropped (the React plugin is always caller-supplied). Added `npm run typecheck` and `npm run verify`.                                                                                                                                                                                                                                     |
| D9  | **Footer copyright year** came from `new Date()` inside a prerendered component — stale in static HTML until redeploy, and a hydration mismatch on New Year.                                                                                                                                                                         | Injected once at build time via Vite `define`, so both bundles carry the identical literal.                                                                                                                                                                                                                                                      |
